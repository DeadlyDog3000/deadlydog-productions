At a glance

Every number by period. Hover a row for exactly what it counts.

How it's going

Rates worked out from the numbers above, so you can see where people drop off. A rate needs at least a few people behind it to mean much: the count it's from is under each one.

New downloads each day

Mac and Windows installers together, by your days. Counted while this panel runs: downloads on a day it was off show on the next day it ran.

Players online, last 7 days

Sampled every two minutes while this panel runs.

Players per day

Different installs that started the game each day (the game server's own count).

Who's playing

Each install as it was when it was last started.

Latest sales

 

All your games

What's counted for each one. “7 days” is the last 7 days.

Reviews

What players have written on the game pages, newest first.

Time played

Minutes of real play in each game, from a beat a minute while a game is open and its window in front (never the menu, a pause or a hidden tab). Your own browser isn't counted. Counting began when each game started sending it.

Mailing list

People who signed up on the website and confirmed by email.

Keys given away

Free copies of Forester: Reckoning for creators and the press. Never counted as sales. Each works on 3 computers, like a bought key.

Errors in players' games

Error reports from players who said yes to sending them, grouped by error, the latest first. Each is the error and where in the code it happened, the version and the screen: nothing about the player.

Visits to the website and the browser games

Counted by your game server when a page opens. A person who comes back on the same day is counted once in "people". Your own visits aren't counted, and views that came from a page on this computer are taken off.

Traffic to each game's GitHub page

Views of each game's page on github.com, from GitHub's own counts. GitHub only keeps the last 14 days, so this panel saves every day it sees, and the charts grow longer from today. Visits to the website itself are counted above, under Visits.

Every release file

GitHub's own counts. They count every fetch of the file: your own tests, our checks that a new upload works, and link-checking bots, not only players. A file uploaded again starts at nought on GitHub; this panel carries the old count forward. Fetches we know were our own (listed in data/own-downloads.json) are taken off. For real people, see Players.
